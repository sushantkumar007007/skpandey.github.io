My research is positioned at the intersection of Artificial Intelligence and Software Engineering. The common thread is **empirical rigour**: understanding not only whether AI-driven methods work, but under which conditions, for which kinds of systems and with what trade-offs, especially in domains where correctness and dependability are non-negotiable.

## AI for Software Engineering

How large language models and other AI techniques can support software development, maintenance and evolution.

- **Code migration and transformation with LLMs:** dependency-aware repository migration across languages (ASE 2026), cross-language semantic clone detection (SEAA 2026)
- **Refactoring and maintenance:** automated extract-method refactoring with open-source LLMs (AIware 2025), adapting small language models to maintenance and refactoring tasks (PROFES 2025)
- **Design patterns and software architecture:** design pattern recognition with LLMs and programming language models (EMSE 2025, ESEM 2023, ICSA-C 2024, PROMISE 2023), and how design patterns are understood and used in the automotive industry (PROFES 2023)
- **AI agents for legacy systems:** evaluating GUI agents on legacy workflows (ICSME 2026)
- **Software metrics and evolution:** generating software metrics for future versions of a system (EASE 2025)
- Empirical evaluation of AI tools in industrial software engineering workflows

## AI for Software Testing

Using AI to find, predict and localize faults earlier and more reliably.

- **Fault and defect prediction:** deep learning and ensemble models for bug prediction (ESWA 2020), defect-count estimation across versions and projects (KBS 2020, KBS 2021, ISSE 2025, SN CS 2023), and just-in-time cross-project fault prediction (AST 2023)
- **Empirical foundations of defect prediction:** noise and class imbalance (Soft Computing 2021), whether deep learning is good enough for defect prediction (ISSE 2025), and a survey of ML-based fault prediction (ESWA 2021)
- **Fault localization:** LLM-based and agent-based fault localization, particularly for robotic software
- **Testing AI-based systems:** input prioritization for testing deep learning models (SEAA 2022)

## AI and Software Engineering for Autonomous and Robotics Systems

Applying AI and SE methods to autonomous, robotic and drone systems, where software complexity, real-time constraints and safety requirements create unique engineering challenges.

- Fault detection, prediction and localization in robotic and drone software (e.g., ROS 2)
- AI-assisted development, testing and code comprehension for robotic software stacks
- Software architecture analysis for cyber-physical and robotic systems
- Data quality for automotive perception: data splitting, annotation and train–test data leakage (VEHITS 2025, IV 2026, CAIN 2026, SN CS 2026, SWQD 2024, QUATIC 2024/2025)

## Trustworthy and Safety-Critical AI

Extending AI-for-SE to settings where reliability and explainability are hard requirements.

- Validation of AI-generated software artifacts
- Explainability and traceability in AI-driven systems
- Trustworthy CI/CD automation with AI agents
